# نظام إدارة الأسطول والمواقع الزراعية

نظام ويب عربي (RTL) لإدارة السيارات والموظفين والوثائق والتفويضات وتغيير الزيت والصيانة والحوادث ونماذج التسليم وصيانة سكن العمال وتوريد الطعام، للشركتين:

| الشركة | المواقع |
|---|---|
| شركة روى الرمال الزراعية | مزرعة الغملاس، مزرعة البركة، مزرعة ارم |
| شركة عبد الرحمن الفهاد | مشتل الغملاس |

## التقنيات المختارة
- **قاعدة البيانات + تسجيل الدخول + تخزين الصور:** Supabase (PostgreSQL مُدار، Auth، Storage).
- **الواجهة:** تطبيق ويب متجاوب يُنشر برابط واحد (يُبنى في المرحلة الثانية).

## حالة المراحل
| المرحلة | الحالة |
|---|---|
| 1. مخطط قاعدة البيانات والعلاقات | ✅ مكتملة ومختبرة (86 اختباراً ناجحاً على PostgreSQL 16) |
| 2. الواجهات العربية المتجاوبة | ✅ تسجيل الدخول، القائمة (جانبية للكمبيوتر وسفلية للجوال)، الشريط العلوي، البحث العام، مركز التنبيهات، لوحة التحكم بالفلاتر والمهام — مختبرة في متصفح آلي على مقاسي الجوال والكمبيوتر |
| 3. السيارات والموظفون والملكية والتفويض والوثائق | ✅ الشركات والمواقع، جدول السيارات وملف السيارة (11 تبويباً)، العداد وتصحيحه، السائق وسجله، التفويض وسجله، الوثائق، الموظفون وملفاتهم والبيانات الحساسة، صفحة الوثائق — 37 فحصاً ناجحاً في المتصفح |
| 4. تغيير الزيت والصيانة والحوادث ونماذج التسليم | ✅ قوائم وفلاتر وإجماليات، نماذج بحساب فوري، صيانة ببنود متعددة وضريبة، حوادث بحالاتها وتحديث حالة السيارة، نماذج تسليم (مسودة/اعتماد) ونموذج رسمي للطباعة — 32 فحصاً ناجحاً |
| 5. صيانة السكن وتوريد الطعام والفواتير والمرفقات | ✅ صيانة السكن والطعام بالضريبة والملخصات حسب الموقع والشركة والشهر، رفع الصور والفواتير من الكاميرا أو الألبوم إلى Supabase Storage مع تصغير الصور، مكتبة المرفقات، حماية الفواتير والوثائق الشخصية بالصلاحيات — 19 فحصاً ناجحاً |
| 6. المستخدمون والصلاحيات وسجل التعديلات والإعدادات والنسخ الاحتياطي | ✅ صفحة المستخدمين بمجموعات صلاحيات جاهزة وتعطيل الحسابات، سجل التعديلات بالعربي مع الفلاتر، الإعدادات (التنبيهات، الزيت، الضريبة)، نسخة احتياطية كاملة وملف استعادة مختبر على قاعدة جديدة — 24 فحصاً ناجحاً |
| 7. Excel: الاستيراد والتصدير والتقارير | ✅ تصدير XLSX حقيقي لعشرة أقسام (عربي، من اليمين لليسار، تواريخ yyyy/mm/dd قابلة للفرز)، استيراد السيارات والموظفين بمعاينة وتحقق وتأكيد دون حذف، 15 تقريراً برسوم بيانية وجداول وتصدير وطباعة — 66 فحصاً ناجحاً |
| 8. الاختبار الشامل | ✅ إعادة حساب مستقلة لكل المبالغ والحالات على أكثر من 4,000 عملية، اختبار حد الألف صف في Supabase، 127 فحصاً أمنياً، النصوص الخبيثة، المناطق الزمنية، الشبكة البطيئة وانقطاعها — كل المجموعات ناجحة (`bash tests/run_all.sh`) |
| 9. دليل النشر والتشغيل | ✅ دليل عربي: المكونات، التكلفة الشهرية، النشر، ملفات قاعدة البيانات، المستخدمون، النسخ والاستعادة، المهام الدورية، حل المشكلات، الأمان |

## تشغيل الاختبارات محلياً
يتطلب PostgreSQL 16:
```bash
PGHOST=/tmp PGPORT=5433 PGUSER=postgres ./tests/run_tests.sh
```


## الإصدار 0.9 — طلب صيانة
استُبدلت شاشة «الصيانة الدورية» بشاشة «طلب صيانة» (نموذج رسمي قابل للطباعة، اعتماد، مرفقات، سجل لكل سيارة). سجلات الصيانة والفواتير السابقة باقية في «سجل فواتير الصيانة» وفي ملف كل سيارة، وتكاليفها ما زالت في التقارير. يتطلب تشغيل 0007_maintenance_requests.sql مرة واحدة.

## الإصدار 1.0 — حقول حرة ووثائق السائق وفاتورة الزيت
الشركة والموقع والسائق تُكتب بحرية؛ القيمة المسجلة تُربط، والجديدة تُسجَّل تلقائياً (شركة/موقع/موظف) فتبقى التقارير والتنبيهات تعمل. يتطلب 0008_free_text_fields.sql.
