# المرحلة الأولى: مخطط قاعدة البيانات والعلاقات

## 1. خريطة العلاقات

```
companies ──< sites                      (الشركة التي يتبع لها الموقع)
companies ──< vehicles.owner_company_id  (الشركة المالكة — مستقلة)
sites     ──< vehicles.site_id           (الموقع الذي تعمل فيه السيارة)
employees ──< vehicles.current_driver_id (السائق الحالي)
employees 1──1 employee_private          (الإقامة/الجوال/الرخصة — حساسة)

vehicles ──< vehicle_assignments   (فترات المسؤولية: من/إلى + نموذج التسليم)
vehicles ──< vehicle_field_history (كل تغيير في السائق/الموقع/المالك/الحالة/اللوحة)
vehicles ──< odometer_readings     (كل قراءة عداد ومصدرها)
vehicles ──< authorizations >── employees
vehicles ──< documents >── employees   (استمارة، فحص دوري / إقامة، رخصة)
vehicles ──< oil_changes
vehicles ──< maintenance ──< maintenance_items
vehicles ──< accidents
vehicles ──< handovers (from_employee, to_employee)
sites    ──< housing_maintenance
sites    ──< food_supplies
أي سجل  ──< attachments  ←→ ملف في Supabase Storage
كل الجداول → audit_log
```

كل عملية مالية (زيت، صيانة، حادث، سكن، طعام) تحمل **أربعة حقول مستقلة**:
`site_id` (الموقع وقت العملية)، شركة الموقع، `owner_company_id` (مالك السيارة وقت العملية)، `payer_company_id` (الجهة التي دفعت).
الموقع والمالك يُحفظان **لقطةً وقت العملية**، فإذا نُقلت السيارة لاحقاً تبقى مصروفاتها السابقة محسوبة على موقعها السابق.

## 2. قواعد العمل المطبقة داخل قاعدة البيانات (لا تعتمد على الواجهة)

| القاعدة | التطبيق |
|---|---|
| التواريخ | تُخزّن `date` معيارية؛ `fmt_date()` تعرض `YYYY/MM/DD` و`fmt_datetime()` تعرض `YYYY/MM/DD HH:mm` بتوقيت الرياض. `parse_app_date()` ترفض 2026/02/31 وتقبل الأرقام العربية. |
| تاريخ اليوم | `app_today()` بتوقيت Asia/Riyadh دائماً. |
| الأرقام الداخلية | تلقائية وثابتة: `VEH-0001`، `EMP-0001`، `OIL-000001`، `MNT-`، `ACC-`، `HO-`، `HSG-`، `FD-`. |
| العداد | لا قراءة سالبة. القراءة الأقل تُرفض برسالة `ODOMETER_DECREASE` ولا تُقبل إلا عبر `correct_odometer()` مع سبب مكتوب، وتُوثّق. العمليات (زيت/صيانة/تسليم) ترفع العداد فقط إذا كانت قراءتها أعلى. |
| الزيت | القادمة = آخر تغيير + الفترة (افتراضي 10,000 لكل سيارة). الحالات: لم يحن (>1,000) / اقترب (1–1,000) / حان (0 حتى −500) / تجاوز (أكثر من −500). الحدود قابلة للتعديل من الإعدادات. |
| الوثائق | آخر وثيقة لكل نوع هي المعتمدة. الحالات: سارية / اقتربت (≤ 90 يوماً) / منتهية / لا يوجد تاريخ / ناقصة. مستوى التنبيه 90/60/30/7 قابل للتعديل. الوثيقة بلا تاريخ **لا تُعرض سارية**. |
| التفويض | يُفحص للسائق الحالي تحديداً؛ تفويض السائق السابق لا يُحتسب. الحالات: ساري / منتهٍ / غير مفوض / غير متوفر / لا يوجد تاريخ. |
| التسليم | المسودة لا تغيّر شيئاً. الاعتماد يغلق فترة السائق السابق ويفتح فترة الجديد مربوطة بالنموذج ويحدّث العداد. النموذج المعتمد مقفل نهائياً. |
| الصيانة | بنود متعددة (قطع/عمل/أخرى)؛ الإجماليات تُحسب تلقائياً. |
| الحذف | ممنوع فعلياً على كل الجداول التشغيلية والتاريخية؛ البديل الأرشفة (`deleted_at`) وتُسجّل في التدقيق. |
| التدقيق | كل إضافة/تعديل/أرشفة: المستخدم، الوقت، الحقول التي تغيّرت فقط. أرقام الإقامة والجوال لا تُحفظ نصاً في سجل التدقيق. |

## 3. الصلاحيات

| الصلاحية | تتيح |
|---|---|
| `view` | عرض البيانات |
| `create` | إضافة السجلات ورفع الصور |
| `edit` | تعديل السجلات وأرشفتها وتصحيح العداد |
| `invoices` | رفع الفواتير ومشاهدتها وتنزيلها |
| `view_sensitive` | أرقام الإقامات والجوالات والرخص وصور الوثائق الشخصية |
| `export` / `import` | Excel |
| `manage_users` | إدارة المستخدمين (منح هذه الصلاحية نفسها للمسؤول فقط) |
| `settings` | الشركات والمواقع والإعدادات |

المسؤول (Admin) يملك كل شيء. أول حساب يُنشأ في النظام يصبح المسؤول تلقائياً، ولا يمكن تعطيل آخر مسؤول.
الصلاحيات مطبّقة في قاعدة البيانات نفسها (RLS)؛ حتى لو تجاوز أحد الواجهة لا يستطيع قراءة ما لا يحق له.

## 4. العروض الجاهزة للواجهة والتقارير
- `v_vehicles_overview` — جدول السيارات كاملاً (المالك، الموقع، السائق، التفويض، الزيت، أقرب وثيقة).
- `v_document_status` — كل الوثائق الحالية وحالتها وأيامها المتبقية.
- `v_vehicle_oil_status` — موعد الزيت والمسافة المتبقية.
- `v_vehicle_authorization` — تفويض السائق الحالي لكل سيارة.
- `v_expenses` — كل المصروفات في جدول واحد (أساس التقارير الشهرية والسنوية).
- `v_followups` — «المهام التي تحتاج إلى متابعة».
- `dashboard_stats(company, site, year, month)` — أرقام لوحة التحكم مع الفلاتر.
